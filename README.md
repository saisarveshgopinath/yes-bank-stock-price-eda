# Yes Bank Stock Price EDA (2005–2020)

Exploratory analysis of monthly Yes Bank OHLC prices from July 2005 through November 2020. The notebook includes data checks, feature preparation, 20 visualizations, and written interpretations of the observed historical patterns.

## Files

- YesBank_EDA_Completed.ipynb — completed EDA notebook
- data_YesBank_StockPrices.csv — monthly OHLC source data

## Run in Google Colab

1. Upload both files to the same Colab session, or upload the notebook and then select the CSV when prompted.
2. Run the notebook from the top.
3. Replace the marked contribution and team-member fields before submission.

## Scope

This is descriptive analysis of the supplied monthly prices. It does not establish causes for price changes and is not investment advice. Price fields are not adjusted for dividends or corporate actions in this dataset.
